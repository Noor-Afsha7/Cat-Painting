# 🐱 Cat Painting

A cute cat illustration created entirely using **HTML and CSS** as part of the freeCodeCamp Responsive Web Design curriculum.

## 🎨 About the Project

This project demonstrates how to create a cat face using HTML elements and CSS styling without using any images or external graphics.

The cat's features, including its ears, eyes, nose, mouth, and whiskers, are built using CSS properties such as positioning, borders, transforms, gradients, and border-radius.

## 🛠️ Technologies Used

- **HTML5** – Structure of the cat illustration.
- **CSS3** – Styling, positioning, shapes, gradients, and transformations.

## ✨ Features

- CSS-created cat face illustration.
- Custom-shaped ears and inner ears.
- Detailed eyes with highlights.
- Nose and mouth created using CSS borders.
- Whiskers positioned using CSS transforms.
- Gradient background and rounded shapes.
